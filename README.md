# OVERDRIVE://STARDUST

A compact arcade action prototype built around one core action: dash as movement, invulnerability, offense, and resource loop.

This repository is the single source of truth for gameplay code, design decisions, and playtest conclusions.

## Current prototype

Open `game/index.html` in a browser.

Controls:
- Move: `WASD` / arrow keys
- Dash: `Space` or pointer click
- Pulse: `Q` (25 Flux)
- Nova: `E` / `Shift` (100 Flux)
- Pause: `P` / `Esc`
- Restart: `R`

Current stages:
1. Stardust Core — mixed arena combat.
2. Formation — deliberate enemy geometry and kill lines.
3. Stellar Current — environmental flow, ending in the Pulsar boss.

See `docs/GAME_DESIGN.md` for current design rules and `docs/PLAYTEST.md` for decisions derived from playtesting.
